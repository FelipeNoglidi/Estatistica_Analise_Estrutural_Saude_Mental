Análise Exploratória de Dados: Saúde Mental de Adolescentes
Estrutura do Projeto
- `download_base.py`: Script para automação do download do dataset via API do Kaggle.
- `limpeza_dados.py`: Script de tratamento e preparação dos dados.
- `analise_exploratoria.py`: Script de geração e exportação dos gráficos estatísticos.
